# ⚔️ 레전드 오브 크로니클: 용사의 여정 (Legend of Chronicle) 🛡️

웹 브라우저에서 바로 즐길 수 있는 2D 레트로 턴제 RPG 게임입니다.

🎮 **[게임 플레이하기 (GitHub Pages)](https://seohy870114.github.io/rpg_game_LOC/)**

---

## 🌟 주요 특징

- **무제한 자유 탐험**: 8개 대륙(마을, 숲, 동굴, 늪지, 설원, 화산, 어둠의 성채, 올림포스)을 자유롭게 이동
- **4단계 전직 시스템**: 10Lv / 20Lv / 50Lv / 100Lv (7개 고유 직업군)
  - 검사, 마법사, 도적, 전사, 흑마법사, 탱커 기사, 힐러
- **방대한 콘텐츠**: 41개 이상의 고유 스킬, 48종 이상의 장비/아이템, 28종의 몬스터 & 보스전
- **사운드 & 그래픽**: 외부 파일 없이 Web Audio API 및 Canvas 2D 픽셀 아트로 구현
- **저장/로드**: 브라우저 로컬 스토리지(`localStorage`) 기반 자동/수동 저장 지원
- **모바일 완벽 지원**: 모바일 화면용 가상 D-Pad 및 액션 버튼 탑재
- **어드민 콘솔**: 진 최종보스 제우스 토벌 시 신의 권능 콘솔 해금

---

## 📁 프로젝트 구조

```
├── index.html            # 게임 메인 뼈대 HTML
├── style.css             # 전체 스타일시트 및 애니메이션
├── js/
│   ├── sound.js          # 🎵 웹 오디오 API 신디사이저 및 BGM/SFX 엔진
│   ├── database.js       # 📚 직업, 스킬, 아이템, 몬스터 데이터베이스
│   ├── player.js         # 👤 플레이어 상태, 스탯 계산, 장비/인벤토리
│   ├── board.js          # 📋 모험 로드맵 게시판 및 진행도 관리
│   ├── maps.js           # 🗺️ 대륙별 맵 그리드, NPC, 포탈 데이터
│   ├── render.js         # 🎨 캔버스 렌더링 및 이펙트 엔진
│   ├── battle.js         # ⚔️ 턴제 전투 시스템 및 보스전 로직
│   ├── input.js          # 🎮 키보드 및 모바일 가상 패드 입력 처리
│   ├── game.js           # ⚙️ 메인 컨트롤러 및 UI/세이브 시스템
│   ├── admin.js          # ⚡ 어드민 콘솔 치트 및 몬스터 편집기
│   └── main.js           # 🚀 게임 진입점 및 전역 초기화
```
